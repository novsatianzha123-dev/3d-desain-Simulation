# 3D Desain dan Simulasi

Koleksi model Autodesk Inventor, assembly, analisis robot bipedal, dan laporan simulasi.

## Isi

- `*.ipt`: part Autodesk Inventor
- `*.iam`: assembly Autodesk Inventor
- `Analisis Robot Bipedal/`: berkas analisis dan hasil terkait
- HTML/PDF/CSV/notebook: laporan dan data pendukung

Buka file CAD memakai Autodesk Inventor. Sebagian file mungkin mengandalkan referensi komponen dalam folder proyek.
